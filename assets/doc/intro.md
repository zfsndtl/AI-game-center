# AI小站 - 项目介绍

## 简介

AI小站是一个集游戏娱乐和实用工具于一体的在线平台，提供多种即点即玩的小游戏和实用工具。

## 功能特性

### 🎮 小游戏模块

- **五子棋** - 经典双人对战和人机对战
- **围棋** - 传统围棋游戏
- **羊了个羊** - 消除类游戏（简单版和挑战版）
- **推箱子** - 经典益智游戏，共10关

### 🔧 实用工具模块

- **足球竞猜** - 足球比赛预测
- **计算器** - 基础计算功能
- **房贷计算器** - 房贷计算
- **取色器** - 颜色选择工具
- **音乐播放器** - 在线音乐播放
- **小小合唱** - 歌曲合集
- **剪辑工具** - 视频剪辑
- **AI技术站** - 技术文档博客

## 技术栈

- **前端**: HTML5, CSS3, JavaScript (原生)
- **样式**: CSS3 动画、Flexbox、Grid
- **渲染**: Canvas 2D
- **Markdown**: Marked.js

## 项目结构

```
AI-game-center/
├── assets/
│   ├── backgrounds/    # 背景图片
│   └── doc/            # 文档目录
├── css/                # 样式文件
├── js/                 # 脚本文件
├── index.html          # 首页
└── *.html              # 各功能页面
```

## 使用方法

1. 启动本地服务器（端口8081）
2. 访问 `http://localhost:8081/index.html`
3. 点击对应图标进入功能
