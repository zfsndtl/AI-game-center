# 「暮归」HTML5 游戏 — 架构设计与玩法规格书

> 版本：v2.0 | 目标：纯 HTML5 可玩原型
> 设计原则：单手操作 · 竖屏优先 · 关卡制 · 3-8分钟一局 · 可随时中断

---

## 一、技术架构

### 1.1 技术选型

| 维度 | 选型 | 理由 |
|------|------|------|
| **渲染引擎** | Canvas 2D API | 零依赖，轻量（< 50KB），移动端性能充足 |
| **框架** | 无框架，纯 Vanilla JS | 无打包负担，即开即用，适合原型验证 |
| **动画** | requestAnimationFrame + delta-time | 60fps 自适应，兼容低帧率设备 |
| **音效** | Web Audio API (OscillatorNode) | 无需音频文件，程序化生成简单音效 |
| **存储** | localStorage | 持久化最佳成绩、已收集碎片、设置 |
| **字体** | 系统字体栈 (PingFang SC) | 零网络依赖，即时渲染 |
| **响应式** | CSS viewport + JS 动态 Canvas | 适配 320px~428px 主流手机宽度 |

### 1.3 渲染分层（Parallax）

| 层序 | 名称 | 滚动速度 | 渲染内容 |
|------|------|---------|---------|
| L0 | 天空层 | 0（静态渐变） | 从暮光橙到夜幕蓝的垂直渐变，随距离推进动态偏移色相 |
| L1 | 远建筑 | 0.15x | 低饱和度深蓝矩形剪影，随机高度 |
| L2 | 近建筑 | 0.4x | 带窗户光点的建筑剪影（窗户随机亮/灭） |
| L3 | 行道树 | 0.7x | 间隔出现的树剪影 + 随机路灯 |
| L4 | 路面层 | 1.0x | 三车道道路，虚线分隔线，路面纹理 |
| L5 | 实体层 | 1.0x | 玩家角色、温暖碎片、障碍物 |
| L6 | UI 层 | 0（固定） | 距离指示器、碎片计数、暂停按钮、提示文字 |

## 二、核心玩法详细设计

### 2.1 游戏规则

```
基础设定：
  - 玩家角色在三车道道路上自动前进
  - 目标：完成三个关卡，击败怪兽，收集温暖碎片
  - 关卡制：共3关，每关距离、速度、怪兽配置不同
  - 没有"死亡"或"失败"——只有"今天的归途结束了"

关卡系统：
  - 关卡1：初遇暮光（500m，速度2.0）
    300m出现第一类怪兽（迷雾游魂）

  - 关卡2：渐入暮色（1000m，速度2.5）
    300m出现第一类怪兽，500m出现第二类怪兽（暗影行者）

  - 关卡3：暮归之路（2000m，速度3.0）
    300m出现第一类怪兽，500m出现第二类怪兽，1000m出现第三类怪兽（暮色恶魔）

车道切换：
  - 左滑 → 切换至左侧车道（如已在最左则无效果）
  - 右滑 → 切换至右侧车道（如已在最右则无效果）
  - 切换动画：0.15s ease-out 平滑过渡

温暖碎片收集（自动）：
  - 碎片从地平线方向迎面飘来
  - 当碎片到达玩家所在位置时，若玩家在相同车道 → 自动收集
  - 不同车道 → 碎片飘过，计为"错过"
  - 没有惩罚，只是收集机会的错过
  - 碎片可用于兑换武器和弹药

障碍物规避：
  - 路面积水、施工路障、拥挤人群等随机出现
  - 仅在关卡前半段出现
  - 碰到障碍物：轻微减速 + "踉跄"动画（不影响最终结果）
  - 障碍物只出现在1条车道，切换车道即可避开

归途完成：
  - 完成全部3关 → 到达家门口
  - 显示本局收获的温暖碎片和今日旅程总结
```

### 2.2 温暖碎片系统

| 碎片类型 | 稀有度 | 出现概率 | 分值 | 视觉特征 |
|----------|--------|---------|------|---------|
| 🌆 城市光影 | 普通 | 70% | 10分 | 金色圆点 + 柔光晕，直径20px |
| 🐾 街角生灵 | 稀有 | 22% | 30分 | 稍大圆点 + 脉冲光环 + 星形粒子尾迹 |
| 🏮 人间烟火 | 极稀有 | 8% | 50分 | 暖橙光球 + 上升粒子轨迹 + 微闪烁 |

**碎片刷新规则**：
- 基础间隔：1.2 ~ 2.5 秒随机刷新一个
- 随距离推进，间隔缩短（归途后半程碎片更密集）
- 同一时刻屏幕上最多同时存在 3 个碎片
- 碎片在道路上以恒定速度从远方飘来（约2秒从出现到到达玩家）
- 每片碎片对应一个短句描述（收集后在结果页展示）

### 2.3 障碍物系统

| 障碍类型 | 出现概率 | 视觉 | 效果 |
|----------|---------|------|------|
| 路面积水 | 50% | 蓝色反光椭圆 | 碰到后减速 30%，持续 1 秒 |
| 施工路障 | 30% | 橙色条纹锥桶 | 碰到后减速 50%，持续 1.5 秒 |
| 拥挤人群 | 20% | 灰色人影群 | 碰到后减速 40%，持续 1 秒 |

刷新间隔：3 ~ 6 秒，随距离缩短

### 2.4 武器系统

玩家可通过收集的温暖碎片兑换武器，用于击败怪兽。

#### 武器类型

| 武器类型 | 兑换成本 | 冷却时间 | 弹药规则 | 特性 |
|----------|---------|---------|---------|------|
| 🏹 弓箭 | 300碎片 | 2秒 | 无限弹药 | 基础远程武器，无需弹药补给 |
| 🔫 手枪 | 500碎片 | 1秒 | 初始50发 | 中级武器，每10碎片可兑换10发弹药 |
| 🔫 冲锋枪 | 800碎片 | 0.5秒 | 初始100发 | 高级武器，每1秒可发射2次（每次1发），每100碎片可兑换50发弹药 |

#### 武器兑换规则

- **弓箭**：300碎片兑换，无弹药限制，适合新手
- **手枪**：500碎片兑换，弹药有限需要补给，10碎片 = 10发子弹
- **冲锋枪**：800碎片兑换，弹药有限，100碎片 = 50发子弹，每次射击发射2发

#### 武器操作

- **射击**：空格键或点击屏幕
- **切换武器**：数字键1/2/3 或点击右侧面板武器按钮
- 武器面板显示：当前武器、剩余弹药、冷却状态

### 2.5 怪兽系统

怪兽会阻挡玩家的归途，需要使用武器击败。

#### 怪兽类型

| 怪兽类型 | 名称 | 生命值 | 移动速度 | 击败奖励 | 出现条件 |
|----------|------|--------|---------|---------|---------|
| Level 1 | 迷雾游魂 | 2 | 1.0 | 20碎片 | 所有关卡300m后 |
| Level 2 | 暗影行者 | 3 | 1.3 | 40碎片 | 关卡2的500m后，关卡3的500m后 |
| Level 3 | 暮色恶魔 | 5 | 1.6 | 80碎片 | 关卡3的1000m后 |

#### 怪兽行为

- 怪兽随机出现在三条车道之一
- 怪兽生成后保持在该车道，不会切换
- 怪兽会缓慢向玩家移动
- 碰撞怪兽会触发短暂减速（1-1.5秒）
- 使用武器击败怪兽可获得碎片奖励

### 2.6 速度曲线

每个关卡有固定的速度设定：
- **关卡1**：速度 2.0（慢速，适应期）
- **关卡2**：速度 2.5（中速，挑战增加）
- **关卡3**：速度 3.0（快速，最终挑战）

```
关卡速度对比：

关卡1 (500m)
速度 ──────────────── 2.0

关卡2 (1000m)
速度 ──────────────────── 2.5

关卡3 (2000m)
速度 ────────────────────────────── 3.0

总距离：3500m
总时长：约5-8分钟
```

## 五、性能与兼容性

### 5.1 性能目标

| 指标 | 目标值 |
|------|--------|
| 帧率 | 60fps（中高端设备）/ 30fps（低端设备自动降级） |
| 首屏加载 | < 2秒（无外部资源依赖） |
| 内存占用 | < 50MB |
| 包体大小 | 单文件 < 80KB（未压缩） |

### 5.2 兼容性

| 平台 | 最低版本 |
|------|---------|
| iOS Safari | 14+ |
| Android Chrome | 90+ |
| Android WebView（微信） | 基于 Chromium 89+ |
| 桌面 Chrome/Firefox/Safari | 近两年版本 |

### 5.3 设备适配策略

- Canvas 宽度 = `Math.min(window.innerWidth, 428)` 
- Canvas 高度 = `Math.min(window.innerHeight, 926)`
- 保持 9:19.5 比例（iPhone 比例），超出部分留黑边
- 车道位置按 Canvas 宽度百分比计算
- 触摸区域覆盖整个 Canvas（无死角）
