🎯产品定位

「暮归」是一款面向城市通勤上班族的治愈系单手休闲手游。游戏以"下班归途"为叙事核心，通过极简的拇指滑动交互，让玩家在暮色中的城市街道上走向家的方向，沿途收集代表城市温暖瞬间的"温暖碎片"。不同于市面上"杀时间"的休闲游戏，「暮归」定位为「情绪过渡工具」——帮助用户在下班通勤的碎片时间里，完成从工作模式到生活模式的温柔切换。

👤目标用户画像
  • 核心用户：25–35岁城市通勤上班族，日均通勤30–60分钟
  • 通勤方式：地铁、公交、步行、打车
  • 核心痛点：下班后情绪疲惫，需要从"工作模式"切换到"生活模式"
  • 游戏偏好：轻度、不肝不氪、画面好看、有温度、随时可停
  • 消费特征：愿意为品质感和情绪价值小额付费
✨核心差异化
  • 情感锚点：以"归家"为主题，与通勤场景深度绑定
  • 设计优先：单手操作是原始设计约束，而非后期适配
  • 情绪价值：帮用户"切换情绪"，而非"消耗时间"
  • 美学追求：暮色暖调、极简诗意、城市温度感
  • 道德底线：不设计上瘾机制、不利用FOMO、不制造焦虑

新的归途

玩家在三车道道路上自动前进，通过左右滑动切换车道收集迎面而来的温暖碎片、规避路面的障碍物。单局以累计行走 5,000 米 到达家门口为终点。游戏无死亡、无失败惩罚——只有"今天的归途结束了"。

🎮 基本规则
  • 玩家角色在三车道道路中央自动前进
  • 关卡制：共3关，每关距离、速度、怪兽配置不同
  • 道路使用透视视角呈现，三车道汇聚于屏幕上方消失点
  • 温暖碎片从消失点方向迎面飘来，可用于兑换武器
  • 路面上随机出现障碍物（仅在关卡前半段）
  • 怪兽会阻挡归途，需要使用武器击败
  • 完成全部3关归途完成，画面渐白 → "到家了"
  • 无法"死亡"——碰到障碍物或怪兽只是减速
🏆 目标体系
  • 首要目标：完成全部3关，到达家门口
  • 次要目标：收集温暖碎片，兑换武器击败怪兽
  • 战斗目标：击败怪兽获取碎片奖励
  • 长期目标：完成多次归途，解锁新场景
  • 无排名竞争：游戏不设排行榜
Section 03

操作系统设计

单手优先的交互模型与输入规范

✋单手操作设计原则

所有交互操作均设计在屏幕下半部拇指自然可达区域。不留死角、不要求双手、不要求精准操作。这是「暮归」区别于大多数"可单手适配但并非为单手设计"的游戏的核心差异。

📱 触摸操作（移动端）
左右滑动切换至相邻车道。滑动距离 > 25px 且水平位移 > 垂直位移时触发。覆盖整个屏幕区域，无死角。
点击屏幕区域备选操作。点击屏幕左 1/3 → 左车道；中 1/3 → 中车道；右 1/3 → 右车道。为不习惯滑动的用户提供替代方案。
点击开始/继续标题画面和结果画面任意位置点击即可开始或重新开始。
自动收集玩家在正确车道时，碎片到达玩家位置自动收集。无需额外点击。
⌨️ 键盘操作（桌面端调试）
← / A切换至左侧车道
→ / D切换至右侧车道
空格 / 回车开始游戏 / 重新开始
🎯 交互容错设计
滑动阈值25px — 低于常规滑动手势阈值（通常30-40px），对轻微滑动更友好
车道切换动画0.15s ease-out 平滑过渡，非瞬间传送，视觉引导明确
连续滑动保护每次滑动后300ms冷却期，防止误操作连续跳车道
屏幕防滚动游戏Canvas通过 touch-action:none 阻止浏览器默认滚动行为
设备方向锁定竖屏锁定，旋转设备不影响游戏布局
/* 触摸手势检测伪代码 */ function handleTouch(touchStart, touchEnd) { const dx = touchEnd.x - touchStart.x; const dy = touchEnd.y - touchStart.y; const dt = touchEnd.time - touchStart.time; // 判定：水平位移 > 25px 且 > 垂直位移 → 滑动手势 if (Math.abs(dx) > 25 && Math.abs(dx) > Math.abs(dy)) { if (dx > 0) moveRight(); // → 右车道 else moveLeft(); // → 左车道 } // 判定：位移小 + 时间短 → 点击手势（备选操作） if (Math.abs(dx) < 20 && Math.abs(dy) < 20 && dt < 300) { const third = screenWidth / 3; if (touchStart.x < third) moveToLane(0); else if (touchStart.x < third * 2) moveToLane(1); else moveToLane(2); } }

碎片刷新规则
  • 基础刷新间隔：1.2 ~ 2.5 秒随机刷新一枚碎片（均匀分布随机）
  • 动态加速：随着归途距离推进，刷新间隔逐渐缩短至 0.6 ~ 1.3 秒
  • 数量上限：屏幕上同时最多存在 4 枚未收集碎片
  • 车道分布：碎片随机出现在 3 条车道中的一条（均匀概率）
  • 运动速度：碎片以恒定速度（180~240 px/s）从消失点飘向玩家位置
  • 到达时间：约 1.8~2.5 秒从生成到到达玩家所在 Y 坐标
  • 收集判定：碎片到达玩家 Y 坐标 ±10px 范围内，且玩家在同一车道 → 自动收集
  • 错过判定：碎片到达玩家 Y 坐标但玩家不在同一车道 → 碎片飘过，计为错过（无惩罚）
  • 不重复车道：连续两枚碎片不会出现在同一车道（提高策略性）

持续时长1.0 秒1.5 秒1.2 秒

障碍物刷新与交互规则
  • 刷新间隔：3.5 ~ 6.5 秒随机，随距离推进逐渐缩短至 2.0 ~ 4.0 秒
  • 数量上限：屏幕同时最多存在 2 个活跃障碍物
  • 车道占用：每个障碍物仅占用 1 条车道，玩家切换车道即可规避
  • 不会连续：同一车道不会连续出现两个障碍物
  • 不会重叠：障碍物不会与碎片同时出现在同一车道的同一位置
  • 减速叠加：如果已在减速中碰到另一个障碍物，减速效果刷新而非叠加
  • 不阻止归途：碰到障碍物只是减速，永远不会导致"死亡"或游戏结束
  • 视觉效果：碰到后屏幕微震 + 角色短暂闪烁 + 碎裂粒子

关卡系统

关卡制设计：距离、速度与怪兽配置

🗺️关卡架构

游戏采用关卡制设计，共3关，每关距离、速度、怪兽配置各不相同，难度递进：

关卡名称距离速度怪兽配置
关卡1 初遇暮光 500m 2.0 300m出现第一类怪兽（迷雾游魂）
关卡2 渐入暮色 1000m 2.5 300m出现第一类怪兽，500m出现第二类怪兽（暗影行者）
关卡3 暮归之路 2000m 3.0 300m出现第一类怪兽，500m出现第二类怪兽，1000m出现第三类怪兽（暮色恶魔）
🎯 关卡规则
  • 关卡进度：每关独立计算距离，完成后进入下一关
  • 速度固定：每关速度固定，不再随距离增加
  • 关卡过渡：关卡切换时显示关卡名称和过渡动画
  • 障碍物：仅在关卡前半段出现
  • 总距离：3500m（500+1000+2000）

Section 05d

怪兽系统

怪兽类型、行为模式与击败奖励

👹怪兽类型

怪兽会阻挡玩家的归途，需要使用武器击败：

类型名称生命值速度奖励出现条件
Level 1 迷雾游魂 2 1.0 20碎片 所有关卡300m后
Level 2 暗影行者 3 1.3 40碎片 关卡2的500m后，关卡3的500m后
Level 3 暮色恶魔 5 1.6 80碎片 关卡3的1000m后
🎯 怪兽行为
  • 随机车道：怪兽随机出现在三条车道之一
  • 固定车道：怪兽生成后保持在该车道，不会切换
  • 缓慢靠近：怪兽会缓慢向玩家移动
  • 碰撞效果：碰撞怪兽会触发短暂减速（1-1.5秒）
  • 击败奖励：使用武器击败怪兽可获得碎片奖励
  • 无死亡惩罚：碰撞怪兽不会导致游戏结束

  • 玩家角色起始位于中间车道，速度为 2.0 km/h
  • 初始 625 米为新手适应期：碎片稀疏，无障碍物，底部显示操作提示
🚶 游戏中
  • 玩家自动前进，不可停止（减速是唯一的速度变化）
  • 左右滑动屏幕切换车道；点击屏幕左/中/右 1/3 区域也可切换
  • 碎片从消失点飘来 → 到达玩家位置时，同车道自动收集
  • 障碍物从消失点飘来 → 同车道碰到后减速，不同车道则安全通过
  • 天空颜色随距离从暮光橙渐变至夜幕蓝
  • 道路虚线分隔线持续向下滚动，提供视觉速度感
  • 街道旁的路灯光晕随天色变暗而逐渐增强
  • 收集极稀有碎片时全屏短暂闪光 + 微震
🏠 归途完成
  • 累计行走 5,000 米后到达家门口，画面渐白过渡
  • 显示结果页面： 🌙 「到家了」大字标题 ⏱️ 本局用时（分:秒） 📊 各类碎片收集数量 💬 随机展示一条本局收集到的温暖故事
  • 按钮：「🏠 再走一程」（重新开始）
  • 最佳成绩自动保存至 localStorage
📊 计分规则
  • 普通碎片（城市光影）：+10 分
  • 稀有碎片（街角生灵）：+30 分
  • 极稀有碎片（人间烟火）：+50 分
  • 归途完成奖励：+100 分（到达 5,000 米）
  • 总分 = Σ(碎片分值) + 归途完成奖励
  • 分数不设排行榜，仅用于个人记录和成就感反馈
  • 错过碎片不扣分，无任何惩罚
🚫 本游戏明确没有的设计
  • 没有生命值 / HP：永远不会"死亡"或"Game Over"
  • 没有时间限制：不急不赶，按自己的节奏走
  • 没有失败惩罚：错过碎片不扣分，碰到障碍物只减速
  • 没有强制广告：不打断游戏流程
  • 没有排行榜：不和别人比较，只和自己对话
  • 没有每日强制任务：想来就来，不想来也不焦虑
  • 没有体力系统：想走几程走几程
  • 没有"肝"和"氪"：碎片概率不随付费变化，不设付费墙
